# Назва проєкту
This C++ program calculates a specific mathematical expression for a given value of `x`
and checks whether the input belongs to the valid domain.

The formula used:f(x) = cos(30/56) + ((24π)/(45e)) * (12 / ((x - 10)(x - 8))) + 5acos(x + 3) - √(x + 6)

The domain of definition: **x ∈ [-4; -2]**

## ⚙️ Technologies Used
- **Language:** C++
- **Libraries:** `<iostream>`, `<iomanip>`, `<cmath>`
- **Preprocessor directive:** `#define _USE_MATH_DEFINES` (to use M_PI and M_E constants)
